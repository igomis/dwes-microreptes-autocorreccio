# Programació d'aula

Esta carpeta conté una còpia versionada de les fitxes de programació d'aula del repositori `dwes-restructuracio-modul`.

La font docent de veritat continua sent:

```text
dwes-restructuracio-modul/docs/01_programacio_modul/
```

El dashboard del professorat d'este repositori llig esta còpia local perquè la vista `Programació` no quede buida quan el projecte d'autocorrecció s'executa sense tindre el repositori de reestructuració com a directori germà.

Quan es modifique la programació d'aula en el repositori docent, cal tornar a sincronitzar estos fitxers i validar el dashboard.
