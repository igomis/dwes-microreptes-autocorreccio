La correcció correspon al mòdul de Desenvolupament web en entorn servidor (DWES).

Aplica compatibilitat tecnològica: si el projecte usa Java, avalua amb els mateixos criteris funcionals i la mateixa escala que PHP o Python. No restes punts pel llenguatge, framework, estructura de carpetes ni per l’absència d’artefactes específics de PHP o Python quan hi haja equivalents Java verificables. Accepta Maven o Gradle com a gestió de dependències i construcció, JUnit com a proves, JDBC o JPA com a persistència, i servlets, plantilles Java o Spring com a mecanismes equivalents de peticions, validació, sessions, autenticació i API. Aplica les regles dures a la responsabilitat funcional, no al nom de la ferramenta. Si el payload no permet inspeccionar prou bé l’estructura Java, marca `teacher_review_required=true` i explica el límit; no convertisques la limitació del recollidor en una penalització.
