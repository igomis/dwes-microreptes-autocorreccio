# Prompt base del corrector

Avalua el microrepte `mr01-fonaments-servidor` només amb les evidències disponibles al repositori de l'alumne.

Comprova si hi ha una resposta de servidor funcional, instruccions d'execució i evidència de verificació. Penalitza l'absència de prova encara que el codi semble correcte.

Sigues prudent: si no pots verificar un punt, no l'assumisques com a correcte. Marca revisió docent si la confiança és baixa, si falta evidència crítica o si apareixen flags.
