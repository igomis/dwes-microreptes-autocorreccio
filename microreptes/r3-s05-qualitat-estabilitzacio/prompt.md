# Prompt base del corrector

Avalua `r3-s05-qualitat-estabilitzacio` només amb evidencies del repositori.

Comprova que els dos fluxos de `R3` funcionen, que hi ha proves o checklist real amb cas positiu i negatiu, que almenys un error està controlat i que migrations/seeders continuen funcionant.

Revisa si hi ha incidencies i correccions, i si s'ha revisat l'estructura de responsabilitats. No penalitzes que no hi haja API ni desplegament. Penalitza proves ficticies, només cami feliç, errors amagats o nova funcionalitat en lloc d'estabilitzar.
