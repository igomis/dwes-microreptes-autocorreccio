# Tests del microrepte

Estratègia de comprovació manual:

- arrancar l'entorn segons el `README`;
- obrir la ruta, vista, endpoint o healthcheck documentat;
- verificar que la resposta està connectada amb el producte;
- fer o revisar un microcanvi de text, estat o dada simple i comprovar que la resposta canvia;
- comprovar que el `README` indica com repetir la prova;
- demanar a l'alumne què passa al servidor quan entra la petició.

Si la ruta funciona però no està documentada, cal penalitzar documentació. Si només hi ha pàgina estàtica desconnectada del backend, cal revisió docent.
