# Prompt base del corrector

Avalua `r4-s01-contracte-servei-api` només amb evidències del repositori.

Comprova que hi ha un contracte inicial d'API: recurs real del projecte, mapa d'endpoints, request/response, errors i codis d'estat mínims. El contracte ha d'explicar quin valor aporta publicar eixa funcionalitat com a servei.

No penalitzes que encara no hi haja endpoint implementat, autenticació completa, consumidor ni documentació final. Sí que has de penalitzar endpoints arbitraris, contracte genèric o documentació que no es pot relacionar amb el producte.

Marca revisió docent si el contracte sembla generat per IA sense adaptació, si falta evidència crítica o si la confiança és baixa.
