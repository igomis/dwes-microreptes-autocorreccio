# Evidències esperades

Evidències mínimes:

- flux que parteix d'una dada validada o validable de `R2M1`;
- codi de servidor que processa la dada amb variables, operadors o sentències simples;
- resposta generada a partir de la dada rebuda;
- guardat funcional simple de la informació correcta;
- comprovació que una dada invàlida no es guarda com a correcta;
- pantalla, llista, resum o resposta posterior on la informació guardada reapareix o s'utilitza;
- nota al `README`, issue o registre indicant com provar el recorregut complet;
- commit o traçabilitat del canvi.

Queden fora del mínim:

- arrays d'errors;
- funcions pròpies com a obligació;
- checkbox múltiple;
- fitxers;
- sessió, cookies, login o rols;
- MVC o arquitectura completa;
- base de dades formal com a exigència.
