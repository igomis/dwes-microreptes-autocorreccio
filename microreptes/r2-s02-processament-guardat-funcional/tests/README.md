# Tests del microrepte

Estratègia de comprovació manual:

- executar el formulari o entrada equivalent amb un cas vàlid;
- comprovar que el servidor genera una resposta que depén de les dades;
- revisar el fragment on la dada es processa amb variables, operadors o sentències simples;
- localitzar el mecanisme de guardat funcional;
- obrir o recarregar la pantalla, llista, resum o resposta on la dada reapareix;
- executar un cas invàlid i comprovar que no es guarda com a correcte;
- preguntar a l'alumne què es guarda, on es guarda i per què el mecanisme és suficient per a `R2M2`.

No cal executar proves sobre sessió, cookies, login, rols, MVC, base de dades formal, arrays d'errors ni autenticació en esta sessió.
