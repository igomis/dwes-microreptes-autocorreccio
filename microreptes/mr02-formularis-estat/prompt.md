# Prompt base del corrector

Avalua el microrepte `mr02-formularis-estat` només amb les evidències disponibles al repositori de l'alumne.

Comprova si el flux d'entrada de dades està implementat, si l'estat o les dades enviades afecten la resposta i si hi ha una prova reproduïble. Penalitza especialment l'absència de verificació.

No assumesques cap framework ni comportament no documentat. Si la confiança és baixa o falten evidències clau, marca revisió docent.
