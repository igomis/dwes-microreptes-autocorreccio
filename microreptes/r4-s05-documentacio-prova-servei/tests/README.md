# Estratègia de prova

1. Seguir la documentació com a tercer.
2. Executar cas correcte.
3. Executar cas d'error o denegat.
4. Comparar documentació, resposta i codi.
5. Revisar incidències i pas a R5.

Ampliació opcional del repte: declaració en `docs/r4-ampliacio.md`, amb referències a implementació i proves. Es revisa separadament en R4M5; el professorat valida 0–1 en la presentació. No altera la nota del microrepte.
