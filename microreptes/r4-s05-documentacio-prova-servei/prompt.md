# Prompt base del corrector

Avalua `r4-s05-documentacio-prova-servei` només amb evidències del repositori.

Comprova que la documentació permet usar l'API: endpoints, request/response, autenticació, errors, proves i incidències. Contrasta documentació, consumidor i comportament real.

No exigisques OpenAPI complet si hi ha documentació usable. Sí penalitza documentació ornamental, proves no reproduïbles, absència de cas d'error o manca de pas justificat a R5.
