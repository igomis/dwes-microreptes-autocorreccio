# Evidències esperades

- README tecnic actualitzat.
- Instruccions d'arrencada.
- Instruccions de BBDD, migracions/fixtures/seeders o script equivalent.
- Instruccions per provar una accio protegida.
- Dos fluxos descrits.
- Decisions tecniques.
- Demo o guio.
- Backlog cap a R4.
- Possible recurs o endpoint.

Des d’una còpia neta i amb una BBDD de prova, seguix el README, reconstruïx les dades i guarda l’eixida d’una suite o checklist executada. Verifica els dos fluxos i els seus errors, la protecció d’accés i el correu d’R3M6. Revisa les responsabilitats. Si detectes una incidència, documenta símptoma, causa, correcció i prova posterior. Si no en detectes, registra les comprovacions executades.

Ampliació opcional del repte: declaració en `docs/r3-ampliacio.md`, amb referències a implementació i proves. Es revisa separadament en R3M7; el professorat valida 0–1 en la presentació. No altera la nota del microrepte.
