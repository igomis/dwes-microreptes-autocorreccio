# Prompt base del corrector

Avalua `r3-s07-tancament-tecnic` només amb evidencies del repositori.

Comprova que el README permet arrancar el projecte, crear BBDD, executar migracions/fixtures/seeders o script equivalent, provar els dos fluxos i verificar almenys una accio protegida. Revisa que hi ha decisions tecniques, demo o guio de demo, backlog del que queda per migrar i possible recurs o endpoint per a `R4`.

No penalitzes que encara no hi haja API implementada. Sí penalitza README generic, instruccions que no coincideixen amb el codi, ocultacio de parts no migrades o falta de BBDD/fluxos demostrables.

## Ampliació global del repte

Este és l'únic microrepte que recull la proposta d'ampliació 9→10 del repte. Avalua el microrepte sobre 10 sense sumar ni penalitzar l'ampliació en les dimensions o en ra_scores. Si el payload inclou repte_extension, completa una proposta separada de 0 a 1 en passos de 0,25. La proposta servix al professorat per valorar-la durant la defensa: no és una validació docent, no modifica final_score_over_10 i no genera cap nota global del repte. Indica evidències concretes i preguntes pendents; no inventes una defensa oral.
