# Evidències esperades

- Flux de `R2` identificat.
- Ruta i controlador o equivalent.
- Model, servei o capa de dades.
- BBDD real implicada.
- Vista, plantilla o resposta visible.
- Formulari, paràmetre o interaccio real processada.
- Si crea o modifica dades: formulari server-rendered, GET/POST, CSRF, valors previs, errors i redireccio després de l'exit.
- Validacio real en servidor i error controlat.
- Prova del cas positiu amb canvi en BBDD.
- Prova d'entrada invalida sense efectes parcials.
