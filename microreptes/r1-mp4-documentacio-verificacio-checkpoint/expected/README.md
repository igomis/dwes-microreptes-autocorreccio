# Evidències esperades

Evidències mínimes:

- `README` final executable;
- directori de documentació dins del repositori;
- índex o pàgina visible que enllaça fitxes, decisions i verificacions;
- justificació tècnica curta o ADR inicial;
- registre d'incidències i correccions;
- evidència d'arrencada i del punt d'entrada funcional;
- AI log si hi ha ús rellevant d'IA;
- defensa oral, acta de checkpoint o guió individual curt;
- nota de pas a `R2` amb pendent i primer flux previst.

La documentació ha de ser coherent amb el sistema real. Un README ben redactat però no executable és evidència insuficient.
