# Prompt base del corrector

Avalua el microrepte `r1-mp4-documentacio-verificacio-checkpoint` només amb les evidències disponibles al repositori de l'alumne.

Este microrepte correspon al `MP4` del `Repte 1`: documentació tècnica, verificació i checkpoint de pas a R2.

Comprova si el repte queda tancat i defensable:

- `README` final amb requisits, arrencada, parada, serveis, URL i resultat esperat;
- directori de documentació dins del repositori;
- fitxa de MP1, decisió tècnica, incidències i comprovacions incorporades al repo;
- índex o pàgina visible que enllaça eixa documentació;
- justificació tècnica curta o ADR inicial;
- evidència de validació: arrencada, punt d'entrada funcional, captures, logs o acta de checkpoint;
- AI log quan hi haja ús rellevant d'IA;
- pendent o primer pas previst cap a R2.

No valores només la bellesa del README: ha de correspondre amb el sistema real. Penalitza documentació dispersa fora del repositori, instruccions que no permeten repetir la prova, enllaços trencats o defensa memorística sense evidència tècnica.

Sigues prudent: si no pots verificar un punt, no l'assumisques com a correcte. Marca revisió docent si la confiança és baixa, si falta evidència crítica o si apareixen flags.
