# Tests del microrepte

Estratègia de comprovació manual:

- seguir només el `README` per arrancar o revisar l'arrencada;
- comprovar que el `README` inclou parada, ports, serveis i URL del punt d'entrada;
- obrir el punt d'entrada funcional documentat;
- localitzar la documentació del repte des d'un índex o pàgina visible;
- contrastar justificació, incidències, commits i resultat final;
- revisar AI log si hi ha ús rellevant d'IA;
- fer una pregunta individual sobre el paper de cada servei o sobre el primer pas cap a `R2`.

Si falta temps per a defensa completa, és acceptable una acta de checkpoint o guió individual curt, sempre que estiga vinculat al repositori i a evidències verificables.
