# Evidencies esperades

- registre o alta mínima d'usuari;
- usuari guardat en array, fitxer o estructura equivalent;
- contrasenya guardada amb hash;
- login o mecanisme equivalent;
- comprovacio de credencials en servidor amb verificacio de hash;
- sessio autenticada o equivalent;
- logout o invalidacio;
- operacio real del domini protegida;
- cas no autenticat denegat;
- cas autenticat permés;
- README amb forma de registre, usuaris de prova i passos;
- commit o traçabilitat.

Fora del minim: rols avançats, OAuth, JWT, registre públic complet, recuperacio de contrasenya, base de dades i arquitectura completa.
