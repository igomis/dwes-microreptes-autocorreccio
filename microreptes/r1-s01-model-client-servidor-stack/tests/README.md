# Tests del microrepte

No hi ha tests automàtics de codi per a este microrepte, perquè el lliurable principal és una decisió tècnica documentada.

Estratègia de comprovació:

- revisar que la fitxa o document equivalent existeix al repositori;
- comprovar que diferencia client, servidor, navegador, runtime i servidor web;
- comprovar que l'explicació està aplicada al producte propi, no a un exemple genèric;
- verificar que la decisió tècnica és coherent amb el marc docent del curs;
- contrastar oralment preguntes com:
  - quina part del producte s'executa al client i quina al servidor?
  - per què esta opció és assumible per al curs?
  - quina alternativa has descartat i per què?
  - què fa el runtime o servidor triat dins del flux d'execució?

Si el repositori només inclou captures d'IA, una comparativa llarga sense decisió o una justificació desconnectada del producte, cal marcar-ho com a evidència insuficient.
