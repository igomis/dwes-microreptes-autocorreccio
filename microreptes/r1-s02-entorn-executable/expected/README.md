# Evidències esperades

Evidències mínimes:

- configuració Docker o equivalent amb servei web, `PHP`, BBDD i phpMyAdmin;
- estructura inicial del projecte adaptada;
- `README` amb requisits, ordres d'arrencada, ordres de parada, ports i URL;
- comprovació del servei web;
- comprovació de BBDD i phpMyAdmin, o error documentat amb pla de correcció;
- registre d'una incidència, dubte o decisió tècnica;
- commit o traçabilitat equivalent de l'entorn.

L'entorn pot no estar completament resolt si hi ha un bloqueig real, però el bloqueig ha d'estar documentat amb log, hipòtesi i pròxima acció concreta.
