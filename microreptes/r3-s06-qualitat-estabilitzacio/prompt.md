# Prompt base del corrector

Avalua `r3-s06-qualitat-estabilitzacio` només amb evidencies del repositori.

Comprova que els fluxos principals de `R3` funcionen, que hi ha proves o checklist real amb cas positiu i negatiu, que almenys un error està controlat, que la BBDD es pot reconstruir i que la proteccio d'accessos de `R3M5` continua funcionant.

Revisa si hi ha incidencies i correccions, i si s'ha revisat l'estructura de responsabilitats. No penalitzes que no hi haja API ni desplegament. Penalitza proves ficticies, només cami feliç, errors amagats o nova funcionalitat en lloc d'estabilitzar.
