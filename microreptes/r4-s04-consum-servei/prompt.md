# Prompt base del corrector

Avalua `r4-s04-consum-servei` només amb evidències del repositori.

Comprova que hi ha consumidor mínim, col·lecció o script que crida l'API real, mostra cas correcte i cas d'error, i inclou instruccions de reproducció.

No exigisques una app client completa. Sí penalitza consum ornamental, proves només manuals sense registre o consumidor que no envia credencial quan cal.
