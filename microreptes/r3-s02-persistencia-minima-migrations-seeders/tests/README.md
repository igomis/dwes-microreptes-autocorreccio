# Estratègia de prova

1. Reiniciar o crear BBDD.
2. Executar migracions o equivalent.
3. Executar migracions o mecanisme equivalent i carregar fixtures/seeders o script equivalent.
4. Comprovar dades carregades.
5. Executar lectura real des de l'aplicacio o consola.
6. Revisar on s'usa eixe conjunt de dades.
