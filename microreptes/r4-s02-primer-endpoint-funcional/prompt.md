# Prompt base del corrector

Avalua `r4-s02-primer-endpoint-funcional` només amb evidències del repositori.

Comprova que existeix un endpoint accessible, que retorna resposta estructurada i que usa dades o lògica real del projecte. Contrasta la resposta amb el contracte de R4M1.

No penalitzes que encara no hi haja consumidor complet ni documentació final. Sí penalitza endpoints decoratius, dades simulades sense justificació, resposta inconsistent o absència de prova reproduïble.
