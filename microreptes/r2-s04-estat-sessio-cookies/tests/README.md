# Proves recomanades

1. Executar el flux i guardar la dada temporal.
2. Fer una peticio posterior i comprovar que la dada es recupera.
3. Executar l'accio d'invalidacio.
4. Repetir la peticio posterior i comprovar que la dada ja no s'aplica.
5. Revisar què queda en cookie o sessio si és observable.
