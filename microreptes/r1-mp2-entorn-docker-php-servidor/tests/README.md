# Tests del microrepte

Estratègia de comprovació manual:

- executar o revisar `docker compose up` o ordre equivalent;
- obrir la URL del servei web documentada;
- comprovar que existeixen serveis per a `PHP`, servidor web, BBDD i phpMyAdmin;
- obrir phpMyAdmin o revisar que el servei està definit i accessible;
- seguir el `README` buscant passos ocults;
- demanar a l'alumne què fa cada servei i què ha adaptat respecte del model docent.

Si l'entorn no arranca, comprova que hi ha log d'error, hipòtesi de causa, canvi intentat i pròxima acció.
