# Evidències esperades

Evidències mínimes:

- ruta, vista, endpoint, landing mínima o healthcheck funcional;
- resposta connectada amb el producte o el seu estat inicial;
- prova visible de la resposta: captura, log, URL o demo documentada;
- `README` amb ruta, resultat esperat i instruccions de comprovació;
- commit o traçabilitat associada;
- explicació breu del fitxer o peça que rep la petició i genera la resposta.

No es demana encara un flux complet de formulari, autenticació o persistència.
