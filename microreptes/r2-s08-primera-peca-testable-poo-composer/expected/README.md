# Evidencies esperades

- flux de `R2M7` triat com a punt de partida;
- `composer.json` amb autoload en PHP, `requirements.txt`/`pyproject.toml` en Python, `pom.xml`/`build.gradle` en Java o declaració equivalent;
- càrrega o importació reproduïble de la classe o mòdul amb el mecanisme de la tecnologia;
- classe simple en `src/` o carpeta equivalent;
- regla, comprovacio o càlcul real encapsulat en la classe;
- prova unitària mínima amb PHPUnit/Pest en PHP, `pytest`/`unittest` en Python, JUnit en Java o equivalent;
- execucio documentada de la prova;
- prova de no regressio d'un cas clau del flux;
- pendents per a `R3`;
- commit o traçabilitat.

Fora del mínim: MVC complet, ORM, POO extensa, API externa i reescriptura en framework.
