# Scripts

Scripts Node.js per mantindre el repositori central.

- `validate-config.mjs`: valida fitxers globals, microreptes i coherència bàsica entre `challenge.json` i `rubric.json`.
- `list-challenges.mjs`: mostra els microreptes disponibles amb identificador i títol.

Execució recomanada:

```bash
npm run validate
npm run list:challenges
```
