# R5M1. Consolidació: Selecció de font externa i disseny de la integració

Esta fitxa es consulta després del treball d’aula. Servix per entendre errors i continuar aprenent; no és una nova entrega ni una recuperació individual del microrepte. La recuperació, si cal, correspon al repte complet.

## 1. Què cal entendre

Una font externa ha d’aportar dades o capacitats que milloren una acció del producte. Abans de connectar-la cal contrastar documentació, accés, format, límits i comportament si no està disponible.

## 2. Exemple mínim explicat

Per ajudar a triar una visita, es podria usar informació externa d’accessibilitat. Compara una font institucional amb un servei alternatiu i ompli dades reals de les fonts que has consultat:

| Decisió | Què has de contrastar |
|---|---|
| Valor | Quina decisió de l’usuari millora. |
| Accés | URL documentada, credencial si cal i condicions d’ús. |
| Dades | Camps disponibles i identificador per relacionar-los. |
| Viabilitat | Límits, actualització i resposta si falla. |

Mapa de disseny: lloc de la visita → consulta externa → selecció de camps útils → informació d’accessibilitat al producte. Si falta correspondència entre llocs, cal explicar com es resoldrà o reduir l’abast. Este exemple és una proposta de domini, no l’afirmació que existix una API concreta; has de validar la font real abans d’adoptar-la.

## 3. Errors habituals

| Què observes | Causa possible | Com comprovar-ho |
|---|---|---|
| Font recomanada per IA però inexistent | No s’ha contrastat la documentació. | Obri la font original i verifica l’accés. |
| La integració és decorativa | No ajuda cap acció del producte. | Explica una decisió que canviaria gràcies a la dada. |
| No hi ha pla d’error | S’assumix disponibilitat permanent. | Defineix què veurà l’usuari si no respon. |

## 4. Modificació curta per practicar

Compara dues fonts reals amb els mateixos criteris i escriu un motiu verificable per descartar-ne una. No inventes límits o permisos que no hages consultat.

És pràctica de consolidació, sense lliurament avaluable addicional. Anota el canvi i el resultat; si uses IA, registra la consulta real i com l’has comprovat.

## 5. Comprova que ho entens

| Cas | Resultat esperat |
|---|---|
| Font triada | Documentació i accés contrastables. |
| Font absent o no viable | Decisió de producte i alternativa d’abast explicitades. |

Prediu el resultat abans de provar i explica quina peça el determina. Si no coincidix, localitza la causa amb el professorat en el temps de consolidació.
