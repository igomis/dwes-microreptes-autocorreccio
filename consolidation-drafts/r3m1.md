# R3M1. Consolidació: Arrencada del nou projecte

Esta fitxa es consulta després del treball d’aula. Servix per entendre errors i continuar aprenent; no és una nova entrega ni una recuperació individual del microrepte. La recuperació, si cal, correspon al repte complet.

## 1. Què cal entendre

Una base en framework ha d’arrancar i seguir les seues convencions. Migrar des de PHP directe no significa copiar tot el projecte antic: cal acotar dos fluxos i explicar què canvia de lloc.

## 2. Exemple mínim explicat

En visites al centre, el primer flux serà consultar visites i el segon sol·licitar-ne una. Abans de construir-los, dibuixa el canvi:

| Abans | Després en el framework |
|---|---|
| Fitxer PHP que rep la petició | Ruta i controlador. |
| Càlcul mesclat amb HTML | Lògica separada de la plantilla. |
| Configuració dispersa | Configuració d’entorn documentada. |

Arranca amb les ordres reals del teu projecte i visita la ruta inicial. Assenyala la definició de ruta, el controlador i la resposta. Una comparativa útil explica per què el framework triat encaixa amb estos dos fluxos i quin cost d’aprenentatge assumixes. El mapa mostra una intenció de reconstrucció, no dos fluxos ja acabats.

## 3. Errors habituals

| Què observes | Causa possible | Com comprovar-ho |
|---|---|---|
| Només es veu la portada del framework | No s’ha situat una ruta pròpia. | Canvia una resposta controlada per tu. |
| Arranca amb secrets locals no documentats | Falta configuració reproduïble. | Contrasta `.env.example` i instruccions. |
| Es migra tot de colp | No hi ha frontera del repte. | Escriu dos casos d’ús concrets i el que queda fora. |

## 4. Modificació curta per practicar

Canvia la resposta de la ruta inicial perquè identifique el teu producte. Explica quins fitxers intervenen i quins encara no necessites.

És pràctica de consolidació, sense lliurament avaluable addicional. Anota el canvi i el resultat; si uses IA, registra la consulta real i com l’has comprovat.

## 5. Comprova que ho entens

| Cas | Resultat esperat |
|---|---|
| Entorn preparat segons README | Ruta inicial accessible. |
| Ruta inicial canviada | La resposta canvia sense editar el nucli del framework. |

Prediu el resultat abans de provar i explica quina peça el determina. Si no coincidix, localitza la causa amb el professorat en el temps de consolidació.

## 6. Connexió amb el pas següent

R3M2 prepararà BBDD i dades inicials. Encara no s’exigixen persistència, dos fluxos complets ni API en R3M1.

Consulta la [rúbrica de R3M1](../../03_com_s_avalua/rubriques/r3m1.md) per distingir els mínims del treball d’aula de les variants d’esta fitxa. L’exemple és de suport i no substituïx el teu projecte.
