# R5M3. Consolidació: Transformació, mapping i valor afegit

Esta fitxa es consulta després del treball d’aula. Servix per entendre errors i continuar aprenent; no és una nova entrega ni una recuperació individual del microrepte. La recuperació, si cal, correspon al repte complet.

## 1. Què cal entendre

El mapping relaciona camps externs amb significat intern, tracta absències i justifica què es descarta. Mostrar un JSON cru no demostra adaptació al domini.

## 2. Exemple mínim explicat

Una mostra fictícia d’accessibilitat arriba així:

```json
{"place_code":"V12","step_free":true,"updated":"2026-01-10","internal_comment":"camp prescindible"}
```

La transformació proposada és:

| Origen | Transformació | Camp intern i ús |
|---|---|---|
| `place_code` | Relacionar amb el lloc de la visita | Referència del lloc. |
| `step_free` | true → accessible; false → no accessible; absent → desconegut | Etiqueta informativa. |
| `updated` | Conservar i presentar la data segons el format acordat | Context de vigència. |
| `internal_comment` | Descartar si no aporta valor | No es mostra ni es guarda. |

La distinció «desconegut» evita convertir absència d’informació en una afirmació falsa. Esta mostra és didàctica: contrasta els camps i tipus amb una resposta real de la teua font. Mantín la transformació separada del client HTTP i decidix explícitament si guardes el resultat o només el presentes.

## 3. Errors habituals

| Què observes | Causa possible | Com comprovar-ho |
|---|---|---|
| Camp absent es tracta com false | S’ha perdut el significat de dada desconeguda. | Prova una mostra sense el camp. |
| Unitats o tipus equivocats | Es copien valors sense interpretar-los. | Escriu tipus, unitat i regla de transformació. |
| La vista coneix tots els camps externs | El mapping no està separat. | Fes que reba una estructura del domini. |

## 4. Modificació curta per practicar

Prepara tres mostres de prova amb true, false i camp absent. Escriu el resultat esperat abans de passar-les per la transformació.

És pràctica de consolidació, sense lliurament avaluable addicional. Anota el canvi i el resultat; si uses IA, registra la consulta real i com l’has comprovat.

## 5. Comprova que ho entens

| Cas | Resultat esperat |
|---|---|
| Camp true en la mostra | Etiqueta accessible. |
| Camp absent | Estat desconegut, sense inventar una dada. |

Prediu el resultat abans de provar i explica quina peça el determina. Si no coincidix, localitza la causa amb el professorat en el temps de consolidació.

## 6. Connexió amb el pas següent

R5M4 connectarà el resultat amb una acció real del producte. La taula de mapping ha de reflectir la font triada, no conservar estos noms ficticis si no corresponen.
