# R2M8. Consolidació: Primera peça testable amb POO i Composer

Esta fitxa es consulta després del treball d’aula. Servix per entendre errors i continuar aprenent; no és una nova entrega ni una recuperació individual del microrepte. La recuperació, si cal, correspon al repte complet.

## 1. Què cal entendre

Una classe testable rep dades explícites i retorna un resultat; no necessita llegir directament POST, sessió ni HTML. Composer resol la càrrega i la prova contrasta una regla real.

## 2. Exemple mínim explicat

Una regla de places pot viure en `src/ReglaPlaces.php`:

```php
<?php
namespace App;
class ReglaPlaces {
    public function accepta(int $places, int $persones): bool {
        return $persones <= $places;
    }
}
```

Configura en el `composer.json` del projecte l’autoload PSR-4 `"App\\": "src/"` i regenera’l amb `composer dump-autoload`. En un script a l’arrel, carrega `require __DIR__ . '/vendor/autoload.php';`, crea `new App\ReglaPlaces()` i comprova que `accepta(4, 3)` és `true` i `accepta(4, 6)` és `false`. La prova ha d’acabar amb codi diferent de zero si un resultat no coincidix; no depengues d’un `assert` desactivable. El controlador recupera i valida l’entrada abans de cridar la classe, i després construïx l’HTML.

Si encara no tens autoload, este és el bloc que has d’integrar en el teu `composer.json`, conservant la resta de configuració:

```json
{"autoload":{"psr-4":{"App\\":"src/"}}}
```

Després de `composer dump-autoload`, guarda `prova-regla.php` a l’arrel:

```php
<?php
require __DIR__ . '/vendor/autoload.php';
$regla = new App\ReglaPlaces();
if ($regla->accepta(4, 3) !== true || $regla->accepta(4, 6) !== false) {
    fwrite(STDERR, "La regla no dona els resultats esperats.\n");
    exit(1);
}
echo "Dos casos correctes.\n";
```

Executa `php prova-regla.php`. És una prova automàtica mínima equivalent; si ja uses PHPUnit o Pest, expressa estos casos en l’eina del teu projecte.

## 3. Errors habituals

| Què observes | Causa possible | Com comprovar-ho |
|---|---|---|
| Class not found | Namespace, camí o autoload no coincidixen. | Contrasta nom, carpeta i mapa de Composer. |
| La prova necessita un navegador | La regla llig superglobals o genera HTML. | Passa valors com a arguments. |
| La prova passa però el web falla | No s’ha connectat la classe al flux. | Repetix un cas web de R2M7. |

## 4. Modificació curta per practicar

Canvia la política per reservar una plaça lliure i actualitza primer el resultat esperat d’un cas límit. Després modifica la classe i repetix també la prova web.

És pràctica de consolidació, sense lliurament avaluable addicional. Anota el canvi i el resultat; si uses IA, registra la consulta real i com l’has comprovat.

## 5. Comprova que ho entens

| Cas | Resultat esperat |
|---|---|
| 4 places, 3 persones amb regla inicial | true. |
| 4 places, 6 persones amb regla inicial | false, sense sessió ni petició HTTP. |

Prediu el resultat abans de provar i explica quina peça el determina. Si no coincidix, localitza la causa amb el professorat en el temps de consolidació.
