# R3M2. Consolidació: Persistencia minima amb migracions, fixtures/seeders o equivalent

Esta fitxa es consulta després del treball d’aula. Servix per entendre errors i continuar aprenent; no és una nova entrega ni una recuperació individual del microrepte. La recuperació, si cal, correspon al repte complet.

## 1. Què cal entendre

Una BBDD reproduïble necessita esquema versionat i dades inicials que es puguen carregar. Veure una taula creada manualment no demostra que una altra persona puga reconstruir-la.

## 2. Exemple mínim explicat

Per a visites, una migració o script equivalent crea `visites` amb identificador, títol i places. Un seeder, fixture o script separat carrega «Visita biblioteca, 12 places» i «Visita taller, 8 places». La primera lectura del projecte consulta estes files.

La seqüència en una BBDD de prova separada és: crear l’esquema → carregar dades inicials → llegir-les amb el projecte. Usa les ordres reals del framework i escriu-les en el README. No executes una reconstrucció destructiva sobre dades que necessites conservar. Indica si la càrrega es pot repetir o si pressuposa una base buida; qualsevol de les dues ha de ser reproduïble amb el procediment documentat.

La lectura pot ser una pàgina senzilla o una ordre de consulta de l’aplicació. Ha de demostrar accés real, encara que els dos fluxos complets no existisquen.

## 3. Errors habituals

| Què observes | Causa possible | Com comprovar-ho |
|---|---|---|
| Només funciona en la teua BBDD | L’esquema es va crear manualment. | Reconstruïx en una base de prova nova. |
| Es dupliquen dades inicials | No s’ha definit com repetir la càrrega. | Seguix el procediment dues vegades i contrasta el comportament. |
| La pàgina usa dades fixes | No llig les files persistides. | Canvia una dada de prova i repetix la consulta. |

## 4. Modificació curta per practicar

Afegix una visita a les dades inicials i comprova que apareix després de reconstruir la base de prova amb el procediment documentat.

És pràctica de consolidació, sense lliurament avaluable addicional. Anota el canvi i el resultat; si uses IA, registra la consulta real i com l’has comprovat.

## 5. Comprova que ho entens

| Cas | Resultat esperat |
|---|---|
| Base de prova buida amb procediment complet | Esquema, dades inicials i lectura funcionen. |
| Canvi d’una dada inicial | La lectura reflectix el nou conjunt després de preparar-lo. |

Prediu el resultat abans de provar i explica quina peça el determina. Si no coincidix, localitza la causa amb el professorat en el temps de consolidació.
