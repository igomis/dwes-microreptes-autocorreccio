# R4M4. Consolidació: Consum real del servei

Esta fitxa es consulta després del treball d’aula. Servix per entendre errors i continuar aprenent; no és una nova entrega ni una recuperació individual del microrepte. La recuperació, si cal, correspon al repte complet.

## 1. Què cal entendre

Consumir implica enviar una petició real, interpretar l’estat i usar la resposta. Una pantalla amb dades fixes no comprova el servei i un error no s’ha de presentar com a resultat vàlid.

## 2. Exemple mínim explicat

Un consumidor de visites pot ser una col·lecció de peticions, un script o una pantalla. El recorregut és independent del llenguatge:

```text
enviar petició al servei amb la credencial si cal
si no hi ha resposta: mostrar error de connexió
si l’estat indica error: mostrar l’error controlat
si l’estat és correcte: interpretar el JSON i mostrar el títol
```

És pseudocodi: implementa’l amb l’eina que ja uses. La lectura del JSON també pot fallar; no assumisques que qualsevol resposta és JSON vàlid. Prepara una consulta correcta i una d’error amb el mateix consumidor, i documenta URL base i credencial demo. Un curl que només descarrega text pot servir per explorar, però has d’explicar com s’interpreta el resultat i es tracta la fallada.

## 3. Errors habituals

| Què observes | Causa possible | Com comprovar-ho |
|---|---|---|
| Sempre es mostra «correcte» | No es comprova l’estat. | Prova un recurs inexistent. |
| La pantalla mostra dades antigues després d’error | No actualitza l’estat visible. | Fes una petició correcta i després una incorrecta. |
| Funciona només amb una URL incrustada | La configuració no està documentada. | Canvia la base a l’entorn de prova. |

## 4. Modificació curta per practicar

Fes que el consumidor distingisca una visita inexistent d’un servidor inaccesible. Explica quina informació tens en cada situació.

És pràctica de consolidació, sense lliurament avaluable addicional. Anota el canvi i el resultat; si uses IA, registra la consulta real i com l’has comprovat.

## 5. Comprova que ho entens

| Cas | Resultat esperat |
|---|---|
| Servei correcte | El consumidor usa els camps reals. |
| Resposta d’error | No es presenta com una visita vàlida. |

Prediu el resultat abans de provar i explica quina peça el determina. Si no coincidix, localitza la causa amb el professorat en el temps de consolidació.
