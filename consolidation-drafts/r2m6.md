# R2M6. Consolidació: Mini API d'autenticació per a client

Esta fitxa es consulta després del treball d’aula. Servix per entendre errors i continuar aprenent; no és una nova entrega ni una recuperació individual del microrepte. La recuperació, si cal, correspon al repte complet.

## 1. Què cal entendre

El client necessita un contracte que especifique petició, JSON i estat HTTP. Un token només té valor si el servidor el verifica; retornar-ne un sense comprovar-lo en la ruta protegida no protegix res.

## 2. Exemple mínim explicat

Un client de visites envia credencials a `POST /api/login`. Amb l’usuari demo correcte rep `200` i un token opac; amb credencials incorrectes rep `401`. Després envia el token al recurs protegit:

```http
GET /api/me HTTP/1.1
Authorization: Bearer TOKEN_DE_PROVA
```

És una petició de contracte, no una ordre executable: substituïx ruta i token pel mecanisme real. El servidor busca i valida el token segons el sistema documentat abans de retornar JSON de l’usuari. Un token inventat ha de fallar. Documenta com s’obté i quines limitacions té el token simple; no el presentes com un sistema complet de producció. Si el navegador usa un altre origen, cal contrastar la configuració CORS del projecte: una prova amb curl no comprova eixa restricció del navegador.

### Exemple de comprovació en PHP

Este fragment representa la ruta protegida. El token de prova s’hauria d’haver obtingut abans en el login:

```php
<?php
header('Content-Type: application/json; charset=utf-8');

$capcalera = $_SERVER['HTTP_AUTHORIZATION'] ?? '';
$prefix = 'Bearer ';
$token = str_starts_with($capcalera, $prefix)
    ? substr($capcalera, strlen($prefix))
    : '';

$tokensDemo = [
    'TOKEN_DE_PROVA' => ['id' => 1, 'nom' => 'Aina'],
];

if (!isset($tokensDemo[$token])) {
    http_response_code(401);
    echo json_encode(['error' => 'Token incorrecte']);
    exit;
}

echo json_encode($tokensDemo[$token]);
```

Amb `Authorization: Bearer TOKEN_DE_PROVA` retorna `200` i l’usuari demo. Si canvies un caràcter o lleves la capçalera, retorna `401`. L’array només servix per entendre el recorregut; documenta les limitacions i no uses tokens previsibles ni guardats en el codi en un sistema real.

### Exemple equivalent amb Python (Flask)

```python
from flask import Flask, jsonify, request

app = Flask(__name__)

TOKENS_DEMO = {
    "TOKEN_DE_PROVA": {"id": 1, "nom": "Aina"},
}


@app.get("/api/me")
def perfil():
    capcalera = request.headers.get("Authorization", "")
    prefix = "Bearer "
    token = capcalera[len(prefix):] if capcalera.startswith(prefix) else ""
    usuari = TOKENS_DEMO.get(token)

    if usuari is None:
        return jsonify(error="Token incorrecte"), 401

    return jsonify(usuari), 200
```

Per a la ruta de login, usa `request.get_json(silent=True)` per llegir el cos i `jsonify()` per respondre. Retorna explícitament `200` o `401`. Els dos fragments han de compartir el mateix mecanisme de tokens: retornar-ne un i no comprovar-lo després no protegix res.

## 3. Errors habituals

| Què observes | Causa possible | Com comprovar-ho |
|---|---|---|
| El client no pot interpretar la resposta | S’envia HTML o text de depuració. | Inspecciona cos i Content-Type. |
| Token inventat funciona | No es valida en la ruta protegida. | Envia un valor diferent. |
| Funciona en curl però no en navegador | Pot haver-hi un problema d’origen o preflight. | Observa xarxa i configuració CORS real. |

## 4. Modificació curta per practicar

Canvia un caràcter del token demo i compara estat i cos amb la petició correcta. No publiques tokens reals en captures o logs.

És pràctica de consolidació, sense lliurament avaluable addicional. Anota el canvi i el resultat; si uses IA, registra la consulta real i com l’has comprovat.

## 5. Comprova que ho entens

| Cas | Resultat esperat |
|---|---|
| Login correcte i token vàlid | 200 i JSON coherent. |
| Login incorrecte o token invàlid | 401 i cap dada protegida. |

Prediu el resultat abans de provar i explica quina peça el determina. Si no coincidix, localitza la causa amb el professorat en el temps de consolidació.
