# R2M9. Consolidació: Persistència mínima amb BBDD en PHP

Esta fitxa es consulta després del treball d’aula. Servix per entendre errors i continuar aprenent; no és una nova entrega ni una recuperació individual del microrepte. La recuperació, si cal, correspon al repte complet.

## 1. Què cal entendre

Persistir implica escriure i llegir dades reals en una petició posterior. Una consulta preparada separa la instrucció SQL dels valors; la connexió i les credencials no han d’estar mesclades amb l’HTML.

## 2. Exemple mínim explicat

Una reserva acceptada es guarda en una taula `reserves`. Amb una connexió `$pdo` ja configurada i un nom validat, el nucli és:

```php
$alta = $pdo->prepare('INSERT INTO reserves (nom) VALUES (:nom)');
$alta->execute(['nom' => $nom]);
$consulta = $pdo->prepare('SELECT id, nom FROM reserves WHERE nom = :nom');
$consulta->execute(['nom' => $nom]);
$reserves = $consulta->fetchAll(PDO::FETCH_ASSOC);
```

És un fragment per integrar, no un fitxer autònom: pressuposa connexió PDO, taula amb identificador i columna `nom`. Documenta el teu esquema real i la configuració amb valors d’exemple. Prova l’alta des del flux i la lectura en una nova petició. Un nom com `D'Alcoi` ha de conservar-se com a dada sense trencar la consulta. Escapa el text quan el mostres en HTML.

## 3. Errors habituals

| Què observes | Causa possible | Com comprovar-ho |
|---|---|---|
| Nom amb apòstrof falla | S’ha concatenat SQL amb dades. | Usa el paràmetre preparat. |
| La fila desapareix | S’està llegint un array temporal o una altra BBDD. | Contrasta connexió i lectura posterior. |
| L’error exposa credencials | Es mostra l’excepció completa al client. | Dona un missatge controlat i revisa logs locals. |

## 4. Modificació curta per practicar

Guarda dos noms diferents i consulta només un amb un paràmetre. Comprova que el resultat ve de la taula i no de la petició anterior.

És pràctica de consolidació, sense lliurament avaluable addicional. Anota el canvi i el resultat; si uses IA, registra la consulta real i com l’has comprovat.

## 5. Comprova que ho entens

| Cas | Resultat esperat |
|---|---|
| Alta vàlida i lectura posterior | La fila reapareix. |
| Entrada invàlida | El flux no fa una alta que la validació rebutja. |

Prediu el resultat abans de provar i explica quina peça el determina. Si no coincidix, localitza la causa amb el professorat en el temps de consolidació.
