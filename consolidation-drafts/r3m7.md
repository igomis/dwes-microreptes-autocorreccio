# R3M7. Consolidació: Tancament tecnic

Esta fitxa es consulta després del treball d’aula. Servix per entendre errors i continuar aprenent; no és una nova entrega ni una recuperació individual del microrepte. La recuperació, si cal, correspon al repte complet.

## 1. Què cal entendre

Tancar significa que una altra persona pot arrancar, preparar dades i provar dos fluxos sense preguntes improvisades. Documentar limitacions és part de fer una demo defensable.

## 2. Exemple mínim explicat

Una guia de visites pot organitzar-se així:

| Bloc del README | Informació concreta |
|---|---|
| Arrencada | Requisits, variables d’exemple, ordres i URL. |
| BBDD | Creació, migracions o equivalent i dades demo. |
| Flux 1 | Alta d’una sol·licitud, dades i resultat. |
| Flux 2 | Consulta filtrada, dades i resultat. |
| Protecció | Usuari demo, operació permesa i denegada. |
| Decisions | Què ve de R2, què s’ha reconstruït i què falta. |

Demana a una altra persona que seguixca les instruccions en un entorn de prova. Si has d’explicar oralment una variable imprescindible, eixe pas falta en el document. El backlog cap a R4 descriu candidats a servei; encara no afirma que l’API estiga implementada.

## 3. Errors habituals

| Què observes | Causa possible | Com comprovar-ho |
|---|---|---|
| README diu «executar normalment» | No hi ha ordre ni directori. | Reproduïx-lo sense ajuda. |
| Demo depén de dades personals locals | Falta preparació demo. | Usa dades inicials documentades. |
| El pendent es presenta com acabat | No s’ha contrastat text i producte. | Marca què funciona i què queda fora. |

## 4. Modificació curta per practicar

Intercanvia el README amb una parella i anota el primer pas ambigu. Corregeix el text i torna a provar-lo sense instruccions orals addicionals.

És pràctica de consolidació, sense lliurament avaluable addicional. Anota el canvi i el resultat; si uses IA, registra la consulta real i com l’has comprovat.

## 5. Comprova que ho entens

| Cas | Resultat esperat |
|---|---|
| Arrencada i dades des de la guia | Dos fluxos demostrables. |
| Usuari sense permís | Comportament documentat i controlat. |

Prediu el resultat abans de provar i explica quina peça el determina. Si no coincidix, localitza la causa amb el professorat en el temps de consolidació.
