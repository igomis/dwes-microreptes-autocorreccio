# Esborranys de consolidació

Hi ha 28 fitxes, una per microrepte ordinari, preparades per revisar i publicar després de classe des del dashboard. No es publiquen automàticament en la web de l’alumnat. Les sessions introductòries, tallers sense microrepte propi i ampliacions no generen una fitxa addicional.

Cada fitxa inclou aprenentatges, exemple explicat, errors, pràctica curta, comprovació i connexió següent. Els fragments parcials i el pseudocodi indiquen les seues dependències. En R3 s’usen recorreguts independents del framework; en R5 les mostres fictícies es distingixen de l’evidència de connexió real exigida al projecte.

Els enllaços a rúbriques són relatius al destí de publicació `docs/04_materials/consolidacio/` de la documentació d’alumnat. Els esborranys locals guardats en `tmp/consolidacio/` tenen preferència sobre estos models versionats. La publicació continua sent una decisió docent comuna per a tot l’alumnat.
