# R3M4. Consolidació: Segon cas d'us o ampliacio funcional

Esta fitxa es consulta després del treball d’aula. Servix per entendre errors i continuar aprenent; no és una nova entrega ni una recuperació individual del microrepte. La recuperació, si cal, correspon al repte complet.

## 1. Què cal entendre

Un segon flux aporta una acció o consulta útil nova, usa dades reals i manté viu el primer. Canviar colors o copiar una pantalla no demostra creixement funcional.

## 2. Exemple mínim explicat

Si el primer flux sol·licita una visita, el segon pot consultar les sol·licituds d’una visita amb un filtre. El selector envia l’identificador; el controlador obté les files corresponents; la vista presenta només eixe conjunt i tracta l’absència de resultats.

Prepara dues visites amb sol·licituds diferents. Consulta la primera, canvia el filtre a la segona i explica la diferència en la consulta real. Després executa de nou l’alta del primer flux. La reutilització de model o servei és útil quan expressa la mateixa responsabilitat; no cal copiar el controlador complet per canviar un identificador.

L’exemple usa una consulta com a segon flux: si el teu domini demana una operació diferent, mostra igualment entrada, BBDD, resposta i error.

## 3. Errors habituals

| Què observes | Causa possible | Com comprovar-ho |
|---|---|---|
| El filtre només canvia el títol | La consulta no usa el paràmetre. | Compara les files retornades. |
| Segon flux trenca el primer | S’ha canviat codi compartit sense regressió. | Repetix el cas positiu anterior. |
| Identificador inexistent causa excepció visible | Falta tractar l’absència. | Prova un identificador de prova inexistent. |

## 4. Modificació curta per practicar

Prepara una visita sense sol·licituds i comprova que el segon flux mostra un estat buit entenedor, sense confondre’l amb una fallada tècnica.

És pràctica de consolidació, sense lliurament avaluable addicional. Anota el canvi i el resultat; si uses IA, registra la consulta real i com l’has comprovat.

## 5. Comprova que ho entens

| Cas | Resultat esperat |
|---|---|
| Canvi de visita | Canvien les dades segons el filtre real. |
| Primer flux després del canvi | Continua registrant i mostrant correctament. |

Prediu el resultat abans de provar i explica quina peça el determina. Si no coincidix, localitza la causa amb el professorat en el temps de consolidació.
