# R1M2. Consolidació: Entorn executable, landing inicial i tancament de R1

Esta fitxa es consulta després del treball d’aula. Servix per entendre errors i continuar aprenent; no és una nova entrega ni una recuperació individual del microrepte. La recuperació, si cal, correspon al repte complet.

## 1. Què cal entendre

Arrancar contenidors no prova que el producte siga accessible. Cal distingir servidor web, execució PHP, BBDD i phpMyAdmin, i connectar-los amb una landing que explique el producte.

## 2. Exemple mínim explicat

En una base de préstec de material, la landing «Material disponible» és servida pel backend. El port que obris al navegador és el publicat en el host; dins de la xarxa Docker, la connexió a BBDD usa el nom del servei definit en la configuració, no el `localhost` del navegador.

Des de la carpeta amb el fitxer Compose del teu projecte:

```sh
docker compose config --quiet
docker compose up -d
docker compose ps
docker compose logs --tail=30
```

La primera ordre comprova la configuració; les altres permeten observar arrencada i incidències. Després obri l’adreça documentada i comprova la landing. Un contenidor «running» no garantix que la ruta responga. phpMyAdmin és una eina d’administració, no la pàgina del producte. La configuració ha d’incloure els serveis demanats, encara que la landing no consulte dades.

## 3. Errors habituals

| Què observes | Causa possible | Com comprovar-ho |
|---|---|---|
| La landing no respon | Port, ruta o volum incorrectes. | Contrasta URL del README, ports i logs. |
| PHP es mostra com a text | La ruta no passa per l’executor PHP. | Revisa el servei que atén la petició. |
| Només funciona en el teu ordinador | Hi ha passos o variables no documentats. | Reproduïx el README en una còpia separada. |

## 4. Modificació curta per practicar

Canvia un text de la landing i explica quin fitxer se servix i com arriba el canvi al navegador. Identifica en el Compose on es publica el port.

És pràctica de consolidació, sense lliurament avaluable addicional. Anota el canvi i el resultat; si uses IA, registra la consulta real i com l’has comprovat.

## 5. Comprova que ho entens

| Cas | Resultat esperat |
|---|---|
| Arrencada seguint el README | Landing accessible i serveis identificables. |
| URL incorrecta | Pots localitzar si el problema és de port, ruta o fitxer. |

Prediu el resultat abans de provar i explica quina peça el determina. Si no coincidix, localitza la causa amb el professorat en el temps de consolidació.

## 6. Connexió amb el pas següent

R2S0 prepara PHP i HTML abans dels formularis. No cal afegir login ni funcionalitat complexa per consolidar R1M2. L’ampliació de R1 és separada i docent; no es deduïx d’esta pràctica.

Consulta la [rúbrica de R1M2](../../03_com_s_avalua/rubriques/r1m2.md) per distingir els mínims del treball d’aula de les variants d’esta fitxa. L’exemple és de suport i no substituïx el teu projecte.
